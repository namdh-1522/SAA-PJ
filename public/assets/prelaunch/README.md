# Prelaunch Assets

No dedicated assets here.

The prelaunch page reuses the existing Homepage SAA background image:

**Asset**: `public/assets/home/hero-bg.jpg`
**CSS class**: `.home-hero-bg` (defined in `app/globals.css`)

```css
background-image: url('/assets/home/hero-bg.jpg');
background-size: cover;
background-position: right top;
background-color: var(--color-bg-dark);
```

Do **not** add a separate copy of the image in this directory.
